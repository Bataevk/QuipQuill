# cloud

Тонкий бэкенд QuipQuill: авторизация, шлюз к LLM и эмбеддингам (OpenRouter), очередь RabbitMQ + WebSocket. Игровой логики здесь нет.

Стек: Python 3.13, uv, FastAPI, PostgreSQL, RabbitMQ. Каркас появится в этапе 0.2 — см. [roadmap](../docs/plan/roadmap.md) и [protocol](../docs/architecture/protocol.md).
