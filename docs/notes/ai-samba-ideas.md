# Идеи из AI Samba

AI Samba — агентный сервис работодателя (FastAPI + LangChain/LangGraph + RabbitMQ + Postgres). **Переносятся идеи и паттерны, код пишется заново** (решение 13 в [decisions.md](../architecture/decisions.md)).

Главное отличие: в AI Samba воркер очереди запускает весь агент. У нас агент на телефоне, а воркер только вызывает LLM.

| Идея | Как применяем | Где |
|---|---|---|
| Две общие очереди RabbitMQ (`commands` / `events`), `chatId` внутри сообщения, префикс окружения | `qq.commands` (запросы к LLM) / `qq.events` | [protocol.md](../architecture/protocol.md), этап 2.2 |
| Буфер активной генерации + `resume` с `replay` (TTL 900 с) | Критично: мобильная связь рвётся чаще, чем в браузере | 2.2, 3.4 |
| `ack` даже при ошибке, `reject(requeue=False)` для битого JSON | Как есть | 2.2 |
| Раздельные локи на выполнение и доставку | Лок доставки по `sessionId`; запросы одной сессии не обязаны сериализоваться на сервере — порядок держит клиент | 2.2 |
| WS-контракт: `status / generating / done / error`, `replay` заменяет текст, heartbeat, фильтр по `requestId`, без `status`, если команда не встала в очередь | Плюс `channel` и `meta.speaker` для NPC | protocol.md |
| `content` + `statusKey` в событиях | Ключ для локализованных строк интерфейса | protocol.md |
| BugGuardMiddleware (удаляет `tool_calls` без ответа) | Особенно нужен на мобильных | 4.2 |
| Две истории: рабочая память (изменяемая) и `message_logs` (только дописывается) | `model_messages` и `transcript` | data-model.md, 4.2 |
| SafeSummarization: порог, последние N сообщений, безопасная точка разреза, таймаут и повторы, при неудаче — обрезка с пометкой | Порог ~30K, потолок < 100K (цена Haiku) | 4.2 |
| `update_context` — факты, переживающие сжатие | Инструмент `note` + `WORLD_STATE` | agent.md |
| `dynamic_system_prompt`: замена маркера `{{...}}`, данные в конце, детерминированный порядок | `{{STORY_STYLE}}`, `{{WORLD_STATE}}`; стабильный префикс для кэша | agent.md |
| Инструменты не перечисляются в тексте промпта (иначе три копии одних данных) | Как есть | 4.1 |
| ToolPayloadMiddleware: тяжёлое из истории — в state | Ответы NPC и карточки не попадают в историю мастера целиком | 4.3 |
| Три политики ошибок: конфигурация — падать, внешний сервис — деградировать, инструмент — текст (не больше 3 попыток) | Как есть, плюс явные таймауты | везде |
| Паки (промпт + инструменты + effort) | MVP: режимы мастера (исследование / диалог / бой) и «пакет истории» со своим стилем | backlog |
| Тест целостности промпта (маркер подставлен, ссылки живые) | Тест сборки промпта в 4.1 | 4.1 |
| Health-эндпоинты по зависимостям | `/health/db`, `/health/mq`, `/health/llm` | 2.4 |
| **Пробелы AI Samba:** нет учёта токенов, метрик, оценки качества, `requestId` в логах | Учёт токенов — с первого дня (лимиты тарифов); `requestId` в логах — 2.4; «золотые» сценарии — 6.2 | — |
