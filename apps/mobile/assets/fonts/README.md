# Fonts

The app embeds these fonts unchanged (the expo-font plugin in `app.json` takes the files from the
`@expo-google-fonts/*` packages). Both are under the SIL Open Font License 1.1. The license texts
are in this folder and must ship with the app (an "Acknowledgements" line in the profile, stage D.7).

| Font | Faces used | Copyright | License |
|---|---|---|---|
| IM Fell English | Regular, Italic | © 2010 Igino Marini (the files' notice names Reserved Font Name "IM FELL English Roman") | [IMFellEnglish-OFL.txt](IMFellEnglish-OFL.txt) |
| Literata | Regular, Italic, SemiBold | © 2017 The Literata Project Authors | [Literata-OFL.txt](Literata-OFL.txt) |

OFL allows free commercial use, embedding and changes. Two conditions matter for us: keep the
license with the fonts, and do not sell the fonts on their own. A changed font must not carry a
Reserved Font Name; we do not change the files.

A new font: only under OFL or an equally open license; check its license file first (ADR 63).
